# Resume Positioning Guide

## Strong Resume Bullet Options

- Built an Industry 4.0 analytics platform for glass manufacturing with Streamlit, FastAPI, SQLite, and scikit-learn, covering KPI monitoring, defect prediction, and operational recommendations.
- Designed a reusable Python application architecture with shared analytics and ML modules consumed by both a dashboard and a REST API.
- Developed a synthetic multi-plant manufacturing data pipeline and SQL analytics layer to benchmark throughput, yield, scrap cost, shift quality, and energy intensity.
- Implemented a defect-risk model with preprocessing, threshold tuning, and evaluation using precision, recall, F1, and ROC-AUC instead of accuracy-only reporting.
- Added automated API and analytics tests plus Docker-based local orchestration to make the project reproducible and reviewable.

## How To Talk About It In Interviews

### Problem Framing

Say that you wanted to build a realistic manufacturing AI case, not just a classification notebook. The core business question is how to reduce defects, scrap cost, and delivery delays while maintaining throughput.

### Technical Framing

Emphasize that the project demonstrates full-stack data work:

- data generation and reproducibility
- SQL analytics
- model development and evaluation
- API design
- dashboard productization
- testing and containerization

### Product Framing

Point out that the dashboard is designed for different stakeholders:

- plant leadership needs executive KPIs
- quality engineers need hotspot analysis
- operations teams need recommended corrective actions
- technical reviewers can inspect the API and model metrics
